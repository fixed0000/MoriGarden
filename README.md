# Mori Garden

Одиночная 3D-игра для Windows про выращивание чао, вдохновлённая Chao Garden из Sonic Adventure DX и Sonic Adventure 2. Исследуй сад, ухаживай за питомцами и наблюдай, как они растут, заводят друзей и выбирают любимые занятия. Игра находится в разработке. Интерфейс на английском.

## Запуск

1. Установи [.NET SDK 8](https://dotnet.microsoft.com/download/dotnet/8.0).
2. Дважды нажми [Play.cmd](Play.cmd). При первом запуске он скачает необходимые файлы и подготовит игру. Нужен интернет.
3. Для отдельного редактора питомцев запусти [ChaoEditor.cmd](ChaoEditor.cmd). Для него нужен Python с Tkinter.

## Управление

| Клавиши | Действие |
| --- | --- |
| WASD или стрелки | Ходить |
| Shift, Space, Ctrl | Бежать, прыгать, делать рывок |
| Правая кнопка мыши или IJKL | Повернуть камеру |
| Колесо мыши, C | Изменить расстояние камеры, вернуть её за спину |
| E | Взять или поставить чао либо предмет, потрясти дерево |
| E во время движения с предметом или чао на руках | Бросить |
| X с яйцом на руках | Трясти яйцо; после пяти секунд поставь его, чтобы вылупился чао |
| F | Погладить ближайшего чао; можно удерживать |
| Q, R | Позвать чао, отправить Мори на лежанку поблизости |
| B | Открыть сумку |
| G, H, V | Убрать фрукт, достать обычный фрукт или Heart Fruit |
| Tab, M, Esc | Карточка Мори, музыка, меню паузы |

## Жизнь в саду

Подойди к чао и повернись к нему с фруктом, животным или игрушкой в руках, чтобы передать подарок. Животные развивают навыки: попугай и певчая птичка — полёт, пингвин — плавание, кролик — бег, медвежонок — силу. Плавающие чао подарки не принимают.

В магазине на плазе доступны цветные яйца, фрукты и семена. У каждого чао есть любимый фрукт, игрушка и музыкальный инструмент. Чао самостоятельно гуляют, плавают, отдыхают, играют и знакомятся друг с другом. Через плазу можно посетить отдельный береговой сад Coastal Cove.

Для переименования используй Chao Machine рядом с выходом из сада. В Chao Editor выбери питомца слева, измени нужные параметры и нажми **Apply changes**.

## Сохранения

В меню **Esc → Save Game** и **Esc → Load Game** доступны **20 слотов**. Игра также сохраняется автоматически. Для выхода выбери **Exit Game**.
