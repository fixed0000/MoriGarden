# Mori — маленький сад

Одиночная 3D-игра про выращивание чао для Windows, вдохновлённая Chao Garden из Sonic Adventure DX и Sonic Adventure 2. Сделана на Godot 4.5.1 .NET и C#. Интерфейс игры на английском.

## Запуск

1. Установи [.NET SDK 8](https://dotnet.microsoft.com/download/dotnet/8.0).
2. Дважды нажми [Play.cmd](Play.cmd). При первом запуске лаунчер скачает Godot, затем соберёт и запустит игру.
3. Для отдельного Chao Editor запусти [ChaoEditor.cmd](ChaoEditor.cmd). Нужен Python с Tkinter. [Editor.cmd](Editor.cmd) открывает проект в редакторе Godot.

## Управление

| Клавиши | Действие |
| --- | --- |
| WASD или стрелки, Shift, Space, Ctrl | Ходить, бежать, прыгать и делать рывок |
| Правая кнопка мыши или IJKL, колесо, C | Повернуть камеру, изменить расстояние или вернуть её за спину |
| E | Взять или поставить чао либо предмет, потрясти дерево |
| E во время движения или прыжка с чао на руках | Бросить чао |
| F, Q, R | Погладить ближайшего чао, позвать питомцев, отправить Мори на лежанку, находясь рядом с ней |
| B, G, H, V | Открыть сумку, убрать фрукт, достать обычный фрукт или Heart Fruit |
| Tab, M, Esc | Карточка Мори, музыка и меню паузы |

Повернись к чао, чтобы передать фрукт, игрушку, инструмент или животное. Движение и поворот прерывают передачу. Созревшие фрукты можно стряхнуть с дерева. Арки ведут между садом и площадью. На площади есть **Garden Shop** с яйцами и **Heart Fruit**, а площадка **Stadium Pad** ведёт к прототипной гонке.

## Жизнь чао

- Чао гуляют, отдыхают, плавают, ищут еду и играют. Любимые вещи влияют на выбор занятий. На островок с пальмой можно попасть по дорожке из камней.
- Чао с высоким **Power** могут пройти по платформам к балкону, спрыгнуть с него или взобраться на столб южной террасы. **Fly** влияет на дальность планирования. Чао с низким **Swim** барахтаются, могут заплыть вглубь пруда и самостоятельно выйти на берег.
- Спящие чао переворачиваются без смены направления. **Manners** определяет, будет ли чао чесать спину и раскидывать лапки во сне. После сильного падения чао три секунды лежит, поднимается и две секунды стоит перед тем, как идти.
- Чтобы вылупить чао, удерживай **X** с яйцом на руках больше пяти секунд и поставь яйцо на землю. Яйцо также можно расколоть броском о камень.
- **Heart Fruit** заполняет шкалу готовности. Поставь второго готового чао рядом с тем, кто сидит среди цветов. После встречи появится яйцо цвета одного из родителей.
- Чтобы переименовать чао, встань с ним на нижнюю ступеньку **Chao Machine** и выбери **Rename Chao**.

В Chao Editor выбери питомца в списке слева. Предпочтения находятся во вкладке **Favorites**, воспитанность **Manners** — во вкладке **Hidden**. Кнопка **Apply changes** передаёт изменения в запущенную игру.

## Сохранения

Нажми **Esc → Save Game** или **Esc → Load Game**, чтобы открыть отдельный экран с **20 слотами**. Ручные слоты сохраняют прогресс чао, сумку, зону, позиции и состояние фруктовых деревьев. Текущая анимация и перенос на руках при загрузке сбрасываются.

Автосохранение хранится отдельно в **%APPDATA%/Godot/app_userdata/Mori · маленький сад/pet.json**, ручные слоты — в подпапке **slots**. Игра использует резервные файлы **.bak**, если основной файл повреждён. **Exit Game** закрывает игру с автосохранением.

## Код и проверки

- [PetState.cs](Scripts/PetState.cs) — потребности, навыки, характер и прогресс.
- [ChaoMotion.cs](Scripts/ChaoMotion.cs), [ChaoWander.cs](Scripts/ChaoWander.cs) и [ChaoInterests.cs](Scripts/ChaoInterests.cs) — перемещение, прогулки и выбор занятий.
- [ImportedChao.cs](Scripts/ImportedChao.cs) — позы, мимика и анимации.
- [GardenGame.cs](Scripts/GardenGame.cs) и [SaveStore.cs](Scripts/SaveStore.cs) — управление, интерфейс и сохранения.

Команды проверки из папки проекта

    dotnet build Mori.csproj
    dotnet run --project Tests/Mori.Tests.csproj
    & '.tools/Godot_v4.5.1-stable_mono_win64/Godot_v4.5.1-stable_mono_win64_console.exe' --path . -- --smoke-test

Проверка сцены использует отдельные тестовые сохранения и записывает снимки в папку **artifacts**.
